## 修复

只修改input-issue/index.vue：使用当前列表按批次、员工、项目及OPEN/SUBMITTED状态寻找待处理工单；已知重复项的创建按钮替换为“查看工单 #编号（状态）”，进入对应履历；新入口只读取已有查询数据，不扩大后端授权。其他缺口仍可新建。打开创建前、候选人返回后和保存前均检查已知重复项并提示现有编号，防止填写过程中列表更新后仍重复请求；已就绪项目不再打开创建。已关闭工单不算未关闭重复，后端来源及重开规则仍决定最终能否新建。后端防重、权限、独立复核与事务逻辑不变；前端只反映已加载记录，其他会话并发仍由后端最终校验。
