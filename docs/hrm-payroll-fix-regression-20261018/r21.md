## 修复

- 待独立复核且有复核权的行，仅在`sourceReady === true`时允许“核实关闭”；来源为false/null/缺失时禁用，并提示先补正对应业务来源后刷新，也可退回补正。
- 打开依据前及确认依据后再检查本页来源状态；阻止已知不满足条件的关闭请求。打开弹窗后的服务端来源变化仍由原后端最终检查处理，前端不能保证其他会话未改变来源。
- 退回补正、提交材料、重开沿用原条件；没有把材料提交等同于来源已就绪，没有放宽独立复核或后端授权，没有新增数据库迁移。
