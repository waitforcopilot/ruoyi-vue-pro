# R30 再次提交时清理上一轮当前复核意见（2026-10-18）

## 实际反例与原因

内嵌浏览器使用绑定合成员工8的账号1，在员工端提交工单1的新材料。状态进入“待独立复核”，却仍显示上一轮R21退回意见，见[r30-before.png](r30-before.png)、[页面记录](r30-before.txt)。这会把上一轮意见误作当前轮结果。

后端submit更新材料与状态，却没有清理reviewOpinion。仅给实体赋null仍会被MyBatis-Plus的默认非空更新策略忽略。

## 修复

submit在通过状态、批次、人员及提交权限校验后，清空当前实体的reviewOpinion，并通过显式更新条件将数据库字段置NULL，与材料、状态及SUBMIT事件在同一事务提交。历史REJECT事件及快照不修改。无需迁移，不改前端或授权规则。
