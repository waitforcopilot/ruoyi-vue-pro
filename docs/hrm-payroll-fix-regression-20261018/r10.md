## 修复

- 主体、批次变化同步清空报表、明细、履历及相关弹窗；主体变化同时清空该主体的人员、部门、批次选项和规则。
- 主体级选项/规则、批次级报表、明细和履历均校验请求版本，拒绝旧响应以及同一上下文内先发后到的结果；组件卸载后不回填。
- 编制/审批弹窗确认时校验原上下文，保存及导出结束后也校验上下文，避免旧操作刷新或下载到新页面。保留后端接口、权限和计算规则。
