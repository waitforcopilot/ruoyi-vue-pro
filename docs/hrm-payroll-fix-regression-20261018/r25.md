## 修复

- 补充材料须页面有效、非加载/提交中、当前工单OPEN且canSubmit明确true；提交按钮在操作期间禁用，阻止重复弹窗/请求。
- 操作绑定提交版本、列表版本、工单/批次/员工及可提交状态，确认材料后和POST完成后均检查。旧操作不提交、不弹成功提示、不刷新新页面；已发出的服务器请求不能撤销。
- 刷新、KeepAlive停用及卸载使旧提交失效，并关闭本页拥有的材料弹窗；缓存页面返回后重新加载当前工单及权限，旧列表响应/finally不得覆盖新请求。
- 正常取消/关闭自行结束操作，释放互斥；保留后端最终授权、工单状态与独立复核规则。未修改履历读取逻辑。
