# F-02c 独立分派入口（2026-10-18）

## 行为与边界

起点a1511a1266的分派校验在save内，分派负责人还需内容update权限。本项增加`POST /hrm/payroll/requirement/assign`，请求仅id、version、reviewerId（空值表示取消分派），入口要求query+assign，不要求update。服务器事务锁定行、核对版本，仅基于数据库保存内容构造分派变更，复用F-02b禁止自派/目标有效/query+confirm校验；已确认行改派触发重审清签并保留旧历史。同负责人不生成新版本，仍须权限及预期版本匹配。

列表增加独立“分派”按钮与版本标识弹窗，包含清空负责人入口。普通编辑中的评审负责人始终只读；新需求先保存再分派。前端只发三项分派参数，不把编辑草稿带入请求；取消/关闭不提交，离页、模块或行版本变化不提交旧上下文，提交期间阻止重复调用。为兼容原接口，旧save携带负责人变化仍执行F-02b额外assign鉴权，不放宽任何权限。

复用F-02b菜单权限，无新迁移、角色或授权。本项解决动作入口不独立的问题，不声称项目成员及范围鉴权已实现。
