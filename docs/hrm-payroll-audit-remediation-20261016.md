## F-09：日期输入/输出契约（已修复并运行验证）

HTTP `LocalDate` 统一输出 ISO `yyyy-MM-dd`，不再展示数组。`LocalDateTime` 继续输出毫秒值并兼容原数字/数字字符串输入，新增 ISO 本地时间、空格分隔时间和带时区 ISO 输入；非法类型及文本不能再静默变为时间戳 0。JSON 参数解析错误返回 400，服务端定义错误仍保留服务器异常处理。月度批次的计薪期间必须与所选月份有交集，继续允许已有跨月工资周期。

HTTP Mapper 与内部快照 Mapper 分离，仅为内部日期保留历史数组表示，避免线上的日期展示变化破坏已有冻结来源摘要。旧日期数组仍可反序列化，毫秒时间兼容性不变。

验证：3 项序列化/兼容测试、2 项 Jackson/MVC 测试、27 项月度工资测试通过。Cloud 实际验证 ISO 期间保存正确、字符串/布尔/小数/对象日期输入均返回 400、期间外的 0 毫秒被拒绝；新公式正常创建并独立批准，接口返回 ISO 有效日期。浏览器确认日期正常显示且无脚本错误。见 [API 结果](hrm-prd-remediation-evidence/f09-runtime.json)、[浏览器结果](hrm-prd-remediation-evidence/f09-browser.json) 和 [截图](hrm-prd-remediation-evidence/f09-formula-dates.png)。回归脚本：`scripts/hrm/runtime_date_regression.py`。
