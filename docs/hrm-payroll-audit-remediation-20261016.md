验证：4 项序列化测试、1 项真实 MySQL 集成测试全部通过。MySQL 测试实际执行排序及 LIMIT 查询，确认租户 2 的行不可见；持锁时另一连接修改本租户选中行返回 1205，事务结束后清理测试表。使用环境变量 `HRM_MYSQL_TEST_URL` 启用该集成测试；交付门禁必须设置该变量，不能把默认跳过视为通过。

Cloud 后端重新打包并启动后，真实登录验证 6 个写操作：工资项创建、公式独立审批、薪级创建及独立审批成功，公式和薪级自审均拒绝（1050810005）。见 [运行结果](hrm-prd-remediation-evidence/f01-runtime.json)。本轮复用审计库的隔离目录夹具，不等同于新库核算通过。
