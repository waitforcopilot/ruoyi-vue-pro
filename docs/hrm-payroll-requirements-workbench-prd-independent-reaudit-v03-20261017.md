## 3. 本轮发现

### R-01 / P1：项目范围修改缺少授权动作及确认失效规则

**证据：** L98、L164要求项目保存组织/主体范围和期间；L184又允许需求保存适用范围和期间。L198规定“需求”的范围等语义变更使确认失效，L332定义的确认元组不包含项目范围版本。L383、L387要求发布时项目范围和业务决议有效。L411–425的动作矩阵明确了项目创建、成员管理及需求范围取舍，却未定义修改项目组织/主体/期间的动作和影响规则。

**反例：** 项目P最初针对甲公司、2026年10月，R1～R40按项目范围完成确认。随后把项目范围改成甲乙两家公司或下一计薪期间，需求正文与来源版本不变。若需求继承项目范围，原签字是否仍有效？若需求保存独立范围快照，项目新范围与这些需求旧范围如何校验？当前文本允许两种不同实现，AC-09仅覆盖需求语义变化，无法确定该项目级操作的唯一预期。

**影响：** 发布时可能使用新项目范围搭配旧需求确认，或出现项目与需求范围不一致但仍通过的基线；也可能因“默认拒绝”导致项目范围永远无法修订。此处是PRD未确定行为，不是认定当前代码存在越权。

**建议：** 明确项目范围是否创建后不可变。若允许修改，定义独立动作、项目范围版本、需求继承/显式范围规则、受影响集合、重审及决议更新条件；将范围版本加入确认/发布依赖，或者制定等价的发布一致性校验。不得把针对需求纳入/暂缓的SCOPE_DECIDE默认为项目组织边界编辑权。

**补充验收：** 已确认项目增加主体、修改期间、仅修改项目展示名称各执行一次；预先规定哪些需求失效、哪些保持、旧发布内容如何保留。无权修改拒绝；并发范围修改与确认/发布不能产生新范围配旧授权的结果。

### R-02 / P2：交付质量核验仅显式绑定deliveryVersion，缺少对规格和映射变化的绑定要求

**证据：** L205要求来源语义/映射核验与当前交付质量核验都通过才能可用；L305仅明确“质量核验绑定当前deliveryVersion”。L341–343在规格或转换规则变化时重置来源/关系核验，未明确原交付质量结论是否失效。L351测试了变化后立即不可用，却没有测试规格/映射重新核验完成后，旧交付质量结论能否继续沿用。

**反例：** 交付D1按分钟字段和旧转换规则完成质量检查。随后工时单位改成小时，或R1的汇总/空值规则改变，D1文件本身未替换。完成新规格/映射的语义核验后，若旧质量结论仍只绑定D1，系统可以恢复“已核验可用”；另一实现会要求按新规则重跑D1质量检查。二者都能满足现有“当前deliveryVersion质量通过”的字面条件。

**影响：** 规格正确不代表旧数据满足新规格或新消费规则，“来源可用率”及后续接入准备可能使用过期质量证据。无需为此撤销规格明确的功能确认，缺口位于来源可用判断。

**建议：** 定义质量核验的作用层级。来源级结论至少绑定交付版本和来源语义版本；依赖消费转换的检查还应绑定relationId/mappingVersion。明确变更后的重验集合及可以复用的证据。若选择分离物理数据质量和消费结果质量，也须明确二者共同构成可用条件。

**补充验收：** 固定D1不变，分别改单位、类型和R1转换规则；重新完成语义核验但未重新验证受影响质量时仍不可用；新质量通过后只恢复相应关系，R2按既定影响范围保持或重验。旧质量结论仍在历史中，不覆盖原证据。

### R-03 / P2：强制业务决议未明确纳入发布快照及历史导出的证据闭包

**证据：** L387把实际范围、授权矩阵、状态/变更规则、输出格式及Q-01/02/04/05/07/10决议作为发布条件，要求记录决议ID、批准人、时间和版本。L370–372详列快照对象，但未明确列入这些决议及批准时授权依据；L359–364的六表也没有明确决议字段。L429要求历史签字保留当时授权依据，尚未说明发布对象如何固定并输出这些依据。

**反例：** V1按Q-04授权矩阵D1和Q-05规则决议D2发布。之后调整决议正文、审批状态或矩阵。若V1仅保存需求、来源、问题和人员快照，重新导出时虽能保持六表业务内容不变，却可能只能查询当前决议，无法说明V1当时为什么被允许发布。实现者也可能把决议当作L372“规则引用”处理，但正文并未明确此映射，验收不能只凭推定。

**影响：** 历史内容不漂移与发布依据可审计是两个条件；现有AC-20证明前者，尚不足以验证后者。

**建议：** 明确决议作为发布依赖对象冻结：ID、版本、条款、实际批准人/时间、当时有效的授权依据及决议状态。若使用规则引用机制承载，写明映射关系；在“评审版本说明”或现有其他表中输出可追溯字段，无须增加第七表。明确未生效、撤销或被替代决议对未来发布的影响，历史仍保留当时事实。

**补充验收：** V1发布后修改或替换Q-04/Q-05决议，V1重导出仍能追溯原依据；V2必须使用当前有效决议。发布与决议修改并发时不得混合版本。无权查看依据者按既有受限节选策略处理，不泄露内容也不冒充完整基线。
